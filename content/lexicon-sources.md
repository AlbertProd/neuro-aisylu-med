# Палитра речи Айсылу · 11 октября 2026

Это редакционный словарь для конкретного персонажа, а не частотный рейтинг «400 самых популярных слов». В проверенных источниках такого рейтинга на октябрь 2026 не найдено. В `lexicon.json` 96 уникальных единиц: разговорный интернет-сленг, игровые и романтические выражения, 24 авторских образа и приёма. Определения сформулированы для бота самостоятельно. Авторские выражения не объявляются популярными мемами.

При генерации отправляются только три подсказки: две по теме текущего обращения и одна необязательная идея для нового образа. Можно использовать максимум одну или придумать своё. Остальные слова не увеличивают каждый запрос. Мат отдельно распределён по семи семействам; последние четыре собственных ответа задают паузу для семейства, для «бля/блядь/блять» пауза восемь ответов. Чужой мат не влияет на эту ротацию.

В обычном трёпе модель в одном запросе предлагает два самостоятельных варианта. Локальный отбор штрафует повторы зачинов, четырёхсловных фрагментов, заезженных корней образов и семейств мата. Полные дубликаты собственных ответов не отправляются; повторная междометная «блядь» внутри длинной фразы удаляется. Это снижает повторяемость, но не гарантирует качество каждой шутки. Поиск, сводки, лор, диагноз и медиа используют один обычный ответ. Лимиты слов и денежные ограничения сохраняются; второй вариант немного увеличивает объём вывода одного запроса.
