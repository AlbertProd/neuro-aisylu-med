# НейроАйсылу · MЁD

Чат-бот для уфимского MЁD на **Gemini 3.8 Flash через Polza AI**. Node.js 24+, SQLite. Готовые зависимости закреплены в `pnpm-lock.yaml`.

## Первый запуск

Создай собственного бота через [@BotFather](https://t.me/BotFather). Скопируй `.env.example` в `.env`, заполни `TELEGRAM_BOT_TOKEN`, `POLZA_API_KEY` и свой `OWNER_USERNAME` либо числовой `OWNER_USER_ID`. `.env` хранится только локально или на твоём сервере.

```powershell
pnpm install --frozen-lockfile
node --env-file=.env scripts/check.js
.\start.ps1
```

Если зависимости уже установлены, достаточно `start.ps1`. На Linux: `node --env-file=.env src/index.js`. Нужен один работающий экземпляр. При активном webhook запуск остановится, чтобы не перехватывать существующее подключение.

1. Открой своего бота с аккаунта владельца и отправь `/start`. Бот закрепит твой числовой Telegram ID в базе. После этого смена ника не отдаст доступ другому человеку. Рекомендуется заранее указать `OWNER_USER_ID` в `.env`; при первой привязке по нику обязательно заполни свой `OWNER_USERNAME`.
2. В [@BotFather](https://t.me/BotFather) выбери `/setprivacy` → этот бот → **Disable**. После изменения удали и заново добавь бота в группу. Альтернатива — сделать бота администратором. Не выдавай лишних прав удаления и блокировки: они ему не нужны.
3. Добавь бота в чат MЁD и **сам** отправь там `/bind`. В других группах он молчит и ничего не запоминает. В личке чужим пользователям тоже не отвечает, включая нажатия кнопок.
4. Напиши «айсылу привет» или открой `/menu`. История начнёт собираться с этого момента: Telegram Bot API не предоставляет старую переписку группы.

Бот работает, пока запущен процесс и компьютер подключён к интернету. Для круглосуточной работы подготовлены Dockerfile и [инструкция размещения](DEPLOY.md). Бесплатный тариф с временным диском не сохраняет историю, игры и бюджет после перезапуска. Автозапуск Windows здесь не устанавливается.

| Реплай на голосовое/аудио/видео/фото: `айсылу послушай` или `айсылу что тут` | Разбор вложения и ответ на вопрос |
| `/menu` | Личное меню с кнопками; чужие участники открывают своё |

| `/roast`, `/diagnosis` | Прожарка себя и сатирический выдуманный мемодиагноз |
| `/marry` реплаем | Предложение брака; принять/отклонить может только адресат в течение 10 минут |
| `/divorce`, `/couples` | Развод с подтверждением и последние пять пар чата |
| `/profile`, `/top` | Статистика, репутация, мёд, супруг; топ пяти участников |
| `/daily` | 5–25 виртуальных единиц мёда раз в день; сутки по времени Уфы |
| `/rep +`, `/rep -`, `++`, `--` реплаем | Изменение репутации; одному человеку один голос за сутки, себе нельзя |

Игры и статистика разделены по чатам. Мёд — игровые очки, покупок и платежей нет. Реальная модерация, бан и удаление сообщений не реализованы.

## Характер

20-летняя вымышленная альтушка из Черниковки, из семьи библиотекарши и мастера электроники. Делала музыкальный самиздат, любит Белую, постпанк, башкирскую электронику, чай и странных людей. Пришла поржать, осталась ради своих. На словах «мне похуй», на деле замечает, кому нужна помощь.

Её «PhD по всем областям» — дипломы вымышленного института прикладного пиздеца. Голос: короткий русский, мат по ситуации, зумерская ирония, полезный ответ и один точный подкол. Полная биография, привычки, ограничения и примеры находятся в [content/persona.md](content/persona.md).

40 настроений: **20 позитивных и 20 негативных**. Состояние случайно выбирается на **3–7 ответов**, затем меняется без немедленного повтора. Настроение хранится для всего чата и переживает перезапуск. Оно меняет интонацию, а не правдивость. Позитивные: солнечная язва, медовый угар, пафос под снос, ночная подруга и ещё 16. Негативные: социальная батарейка ноль, едкая рецензентка, недосыпный демон, злая библиотекарша и ещё 16. Все 40 описаны в `src/moods.js`.

Мемодиагнозы всегда обозначаются как выдуманный юмор: «острый дефицит потроганной травы». Настоящие диагнозы и назначения по переписке она не выдаёт. На серьёзные вопросы о здоровье отвечает без прожарки.

Все ответы, меню, уведомления и ошибки проходят общий фильтр: **строчные буквы, максимум 40 слов**, почти без пунктуации. В обычном трёпе, прожарке и щитпосте **80% реплик ограничены 10 словами** и в запросе к модели, и в выходном фильтре. Поиск, сводки и медиа могут занимать до 40 слов. URL источников остаются в кнопках без изменения регистра адреса.

Для разнообразия есть 20 приёмов шутки, семь семейств мата и [палитра из 96 выражений](content/lexicon-sources.md). В запрос попадают только три необязательные подсказки по теме. В обычном трёпе один запрос возвращает два самостоятельных варианта; бот выбирает менее похожий на свои последние ответы по зачину, четырёхсловным фрагментам, образам и мату. Полный дубликат не отправляется. Семейства мата отдыхают четыре собственных ответа, «бля/блядь/блять» — восемь. Это снижает повторяемость без второго платного запроса; небольшой дополнительный вывод двух вариантов тоже оплачивается. Поиск, сводки и медиа сохраняют обычную выдачу.

Характер обновлён после примеров из чата: больше мата, сарказма и мрачного абсурда, меньше лекций и придирок. Мемодиагнозы выдаются только отдельной командой. Приём шутки меняется между ответами и не повторяет последние два; выбранные приёмы сохраняются отдельно для каждого чата. Модель видит свой ID в истории и получает указание не повторять собственные панчи и зачины. Дополнительных ИИ-вызовов для разнообразия нет.

## Медиа и память

Видео, кружки и анимации: **до 120 секунд**, длительность дополнительно проверяет ffprobe. Видео разбирается по выборке до 30 кадров примерно раз в 4 секунды и полной аудиодорожке. Быстрое событие между кадрами может быть пропущено. Это обход ограничения Polza: `video_url` поддерживает только YouTube, поэтому Telegram-видео не передаются таким способом.

Голосовые OGG/Opus и аудио конвертируются в MP3. Аудио ограничено десятью минутами. Фото отправляются напрямую. Общий предел входящего файла — **20 МБ**, соответствующий облачному Telegram Bot API. Более тяжёлый файл нужно сжать перед отправкой. Документы и внешние видеоссылки не скачиваются.

В группе медиа обрабатывается только при обращении к Айсылу в подписи/реплае. В личке владельца — сразу. Непрослушанные вложения в памяти отмечаются честно; сводка не придумывает их содержимое. Краткий разбор обработанного вложения добавляется к его записи, если она ещё входит в последние 50 сообщений. Полная транскрипция не сохраняется.

SQLite хранит максимум 50 текстовых записей на чат, включая ответы бота, плюс игровые профили и настройки. Следующая реплика получает до 49 предыдущих сообщений и текущее обращение: вместе 50. Тексты длиннее 6000 символов обрезаются. Временные аудио и кадры удаляются после обработки. Текст, последние сообщения и обработанные медиа передаются Polza и её провайдеру модели; запроса `поиск` также касается поисковый сервис. Telegram-ссылка с токеном к модели не попадает.

## Команды владельца

| Команда | Действие |
| --- | --- |
| `/bind` | Разрешить работу в этом чате |
| `/status` | Проверить модель, размер памяти и режим щитпоста |
| `/budget` | Расходы сегодня, оставшиеся резервы и квоты поиска/медиа |
| `/ambient on`, `/ambient off` | Включить/выключить самостоятельные реплики |
| `/forget` | Стереть контекст текущего чата, сохранив игры |
| `/unbind` | Отключить чат и удалить его локальную историю, игры и профили |

Самостоятельный щитпост изначально выключен. При включении вероятность 3% на обычное текстовое сообщение, не чаще раза в 15 минут и только после 30 новых сообщений. Все параметры вынесены в `.env`.

Лимиты частоты: 4 секунды между ИИ-запросами участника, 10 запросов в минуту на чат, 120 в час на весь бот. Счётчики сохраняются при перезапуске. Неуспешные вызовы тоже расходуют лимит частоты. Запросы, которые могли дойти до провайдера, автоматически не повторяются. Однократная повторная попытка допускается только при ошибке DNS или установления соединения: платного запроса тогда ещё не было. Игровые команды модель не вызывают.

## Расходы и экономия

Установлен бюджет **100 ₽ в сутки по времени Уфы** на весь бот. Поиск и обработка медиа вместе ограничены **10 запросами в день на бот**, **3 на участника**. Обычная переписка использует отдельную квоту частоты. Владельцу доступна команда `/budget` и кнопка бюджета в личном меню.

Перед платным вызовом резервируются 1,5 ₽ для текста, 4 ₽ для поиска, 3 ₽ для медиа. Если остатка бюджета не хватает на резерв, запрос не отправляется. При получении `usage.cost_rub` или `usage.cost` резерв заменяется фактической суммой. Если цена неизвестна или запрос оборвался после отправки, резерв остаётся до конца суток. Ошибка обработки медиа до обращения к модели и подтверждённая ошибка установления соединения освобождают резерв. Перезапуск, `/forget` и `/unbind` не обнуляют денежный учёт.

Это ограничитель отправки запросов по фактическим расходам и консервативным резервам. **Резерв не является гарантированной максимальной ценой Polza**: если провайдер выставит сумму больше резерва, итог может перейти дневной порог на последнем запросе, после чего дальнейшие вызовы будут заблокированы. Изменения тарифов и расходы других приложений с тем же ключом бот автоматически не узнаёт. Для строгого ограничения списаний всего ключа дополнительно установи дневной лимит ключа в кабинете Polza. Бот не меняет настройки ключа на стороне сервиса.

Модель остаётся Gemini 3.8 Flash, reasoning остаётся `low`. Polza получает сортировку провайдеров по цене и потолки тарифов: 60 ₽ за миллион входных токенов, 300 ₽ выходных, 60 ₽ аудио. Если подходящего провайдера нет, дорогая замена не выбирается. Фактическая цена всё равно зависит от токенов, медиа и поисковой платы. Эти параметры меняются в `.env`.

Лор вынесен в неизменный префикс для автоматического кеширования Gemini. Все 50 сообщений и их тексты сохранены: убраны повторяющиеся имена полей JSON и дублирующиеся подписи авторов. Попадание в кеш зависит от провайдера и отражается в журнале; экономия от кеша не гарантируется. Запас генерации остался прежним — 2048 токенов, включая внутренние рассуждения. Видимый ответ по-прежнему до 40 слов.

Поиск принудительно использует Exa: один проход с тремя результатами вместо непредсказуемых повторных нативных поисков. Это подходит для обычных справок; сложные исследования могут потребовать дополнительного отдельного запроса. Медиа и игровые функции сохранены.

`node --env-file=.env scripts/import-costs.js` импортирует сегодняшние уже оплаченные генерации данного ключа. Повторный импорт не удваивает известные списания. Исторические запросы без данных о режиме учитываются в сумме, но не в квоте дорогих запросов. `node --env-file=.env scripts/check-economy.js` делает два платных теста и учитывает их в общей базе бюджета. Исходный `smoke.js` — отдельная диагностика, его расходы нужно импортировать указанной командой.

## Проверки

```powershell
node --test
node --env-file=.env scripts/check.js
node --env-file=.env scripts/smoke.js
```

Тесты работают локально без отправки сообщений. `check` читает сведения о боте, каталог моделей и проверяет медиаинструменты. Авторизация ключа Polza проверяется реальной генерацией в `smoke`: он делает **четыре небольших платных** вызова — характер, сводка, поиск с источниками, тестовое видео с синусоидой. Сообщений в Telegram он не отправляет.

Документация интеграций: [каталог Gemini 3.8 Flash](https://polza.ai/models/google/gemini-3.8-flash), [поиск Polza](https://polza.ai/docs/gaidy/web-search), [входящие медиа Polza](https://polza.ai/docs/gaidy/media-input), [Telegram privacy mode](https://core.telegram.org/bots/faq#what-messages-will-my-bot-get).

## Публикация и лицензия

Код распространяется под [лицензией MIT](LICENSE). Для собственного запуска нужны свои ключи и аккаунты Telegram/Polza; доступ к действующему боту или его данным вместе с исходниками не передаётся.

Перед коммитом добавь нужные файлы в Git и запусти `npm run check:secrets`. Проверяется именно содержимое индекса Git: `.env`, базы, логи, архивы и известные форматы секретов блокируют публикацию. Ключи, история чата и резервные копии остаются локально и исключены через `.gitignore`.
